# Domain docs

This is a single-context repository.

## Vocabulary

Use `CONTEXT.md` at the repository root for durable portfolio terms, project categories, and naming that agents need to apply consistently. Create it only when vocabulary has actually been resolved.

## Decisions

Use `docs/adr/` for decisions that are difficult to reverse, surprising without context, and the result of a real trade-off. Do not create ADRs for temporary implementation details or ordinary framework choices.

Repository instructions in `AGENTS.md` remain authoritative.
